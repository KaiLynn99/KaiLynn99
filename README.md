## 🤖 AI・機械学習に関心を持ったきっかけ

約800枚の画像を用いて、爪を噛んでいる状態と通常の状態を分類するモデルを学習させ、特定の行動を検知すると警告音が鳴る仕組みを試作しました。

この経験から、**身近な課題をデータとAIで解決できる可能性**に興味を持ち、機械学習を学び始めました。

※ 機械学習の入門的な試作であり、実運用向けの精度検証は行っていません。

### 🛡️ 空軍でのシステム運用経験（2022年～2024年）

韓国空軍で、監視カメラ管理サーバーの運用補助やセンサー点検を担当しました。

センサーの作動状況やログを確認し、異常がある区間をExcelに記録・報告した経験があります。

この経験から、将来は**センサーやログデータを活用した異常検知・予兆保全**に携わり、設備の安定稼働を支える技術を身につけたいと考えています。
